# Vercel deployment

Import this folder/repository with the project root set to the folder containing `index.html` and `vercel.json`.

Build command: leave empty.
Output directory: leave empty.
Install command: `npm install` (or leave Vercel's automatic install).

The site is static HTML/JS at the root. `npm start` is for persistent Node hosting; Vercel does not run it as the web server.

Pages: `/index.html`, `/games.html`, `/chat.html`, `/settings.html`, `/suggest.html`, `/leaderboard.html`.
